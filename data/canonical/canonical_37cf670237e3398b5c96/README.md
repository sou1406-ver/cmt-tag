# Canonical dataset: public review snapshot

Explicitly published at the repository owner's request for inspection.
REBUILD_VERIFIED; QUALITY_REVIEW_PENDING; not an approved annotation/training release.

comments.csv contains 38642 retained records with separate raw/normalized columns, source identity, and 524 retained single-annotator development sentiment labels.
Labels are existing human decisions, not independent test gold. No legacy overall is used as a target.
exclusions.csv records the exact excluded source block without reintroducing its comments into the corpus. Historical decisions remain local.
The workbook is a blank domain/spam review on 200 retained IDs; no ACCEPT or sentiment is prefilled.
Original platform/post provenance for the legacy source remains unverified. This repository does not establish a data license or API annotation permission.
Original source files and full event/provenance ledgers are local; their hashes are recorded below. Do not change IDs or raw text.
